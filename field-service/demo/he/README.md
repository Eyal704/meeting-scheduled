# הדגמת מערכת לחברת גילוי וכיבוי אש — עברית

גרסה נפרדת מהגרסה האנגלית, באותו תהליך: טכנאי בשטח, בדיקת הדוח במשרד, הצעת מחיר לתיקון, ודוח והיסטוריית בדיקות אצל הלקוח. העמוד וסרטון ההדרכה מוצגים מימין לשמאל.

כתובת מקומית: http://127.0.0.1:8769/field-service/demo/he/

מהשורש של המאגר מפעילים:

```sh
python3 field-service/demo/video-source/serve.py
```

אין שלב בנייה לעמוד. HTML, CSS ו־JavaScript מקומיים, גופן Heebo מ־Google Fonts, תמונת המחשה מוטמעת בקובץ, וסרטון, פוסטר וכתוביות מקומיים. השרת המצורף תומך גם בדילוג למיקום אחר בסרטון.

## התאמה לישראל

- עברית טבעית של חברות גילוי וכיבוי אש: ליקוי, תחנת שליטה, חיבור הסנקה, מדי לחץ, בדיקה חוזרת והצעת מחיר לתיקון.
- שמות חברה ואתרים לדוגמה בעברית, כתובת בישראל, לחץ בבר והצעת מחיר בשקלים.
- מדידות ההמחשה: 5.4 בר במנוחה ו־3 בר בזמן זרימה; בבדיקה הקודמת 5.5 ו־3.4 בר. הירידה בלחץ בזמן זרימה היא כ־12%.
- הצעת המחיר לדוגמה: חומרים 250 ₪, עבודה 550 ₪ ובדיקה חוזרת 150 ₪ — סה״כ 950 ₪ לפני מע״מ. לא נשלח דבר.
- אזכורי התקנים הותאמו להקשר המקומי: ת״י 1928 למתזים ות״י 1220 חלק 11 לתחזוקת גילוי אש. אין כאן טופס בדיקה מלא, קביעה של תדירות מחייבת או אישור תקינות.

מקורות למינוח המקומי:

- [מכון התקנים — תחזוקת מערכות גילוי אש לפי ת״י 1220 חלק 11](https://www.sii.org.il/he/fire-6/)
- [מכון התקנים — מתזים ותחזוקה לפי ת״י 1928](https://www.sii.org.il/he/mataz)

## הסרטון

75 שניות, Full HD, עם הסברים כתובים בעברית, צילומים מתוך הדמו העברי, חיווי נגיעה במסך הטכנאי ותנועת סמן במסכי המחשב. כמו בגרסה האנגלית, הסרטון שקט ואפשר להבין את כולו ללא שמע. נוסף גם קובץ WebVTT בעברית.

מקור הסרטון ב־`video-source/`. לאחר התקנת התלויות בו, `npm run capture` מצלם את הדמו העברי ו־`npm run render` מפיק את הסרטון. הנחיות ההפקה המלאות נמצאות בקובץ README של הגרסה האנגלית, תיקייה אחת מעל. קובצי הצילום נוצרים מקומית ואינם נשמרים ב־Git.

## בדיקות

נבדקו תהליך הבדיקה והשליחה, חזרה לטכנאי עם הערה בעברית, אישור הדוח, הצעת המחיר בשקלים, דוחות משנים קודמות, התחלה מחדש, תמונות, יישור RTL וטקסטים במסכים ובחלוניות. נבדקו רוחבי 320, 390, 768, 1024 ו־1600 פיקסלים. הגרסה האנגלית לא השתנתה.

## תמונת שיתוף

נוספה תמונת שיתוף בעברית, 1200×630, עם צילומים מתוך הדמו ופריסה מימין לשמאל. כותרת, תיאור, Open Graph ו־Twitter מותאמים לעברית. כתובות התמונות הציבוריות יפעלו לאחר פרסום השינויים.
