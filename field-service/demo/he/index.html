שלחו טופס ודוח לדוגמה

שלחו טופס בדיקה אחד ודוגמה לדוח שיוצא ממנו. אכין דוגמה עובדת של המילוי בטלפון ושל טיוטת הדוח, כדי שאיש השטח ומי שבודק את הדוח יוכלו לנסות את אותו התהליך.

ללא עלות וללא התחייבות. בתוך 3 ימי עבודה; אם הטופס דורש יותר זמן, אעדכן מראש.

    לאן לשלוח לכם את הדוגמה?

    דוגמה לטופס אחד, ללא עלות. אם נדרש יותר זמן, אעדכן לפני הבנייה.

    לקריאת ההסבר

    מהבדיקה בשטח לטיוטת דוח.
    בלי להקליד את אותם הנתונים מחדש במשרד. תהליך שנבנה לפי טופסי הבדיקה והבקרה שלכם.

    הבדיקה הסתיימה. הדוח עוד בעבודה.
    מדידות, תמונות ושאלות להשלמה עדיין יכולים להיות מפוזרים בין קבצים. מתחילים במעבר אחד: מהתיעוד בשטח לטיוטה במשרד.

    1. פרטי האתר נשמרים. תוצאות חדשות מזינים.
    האתר והמערכת כבר מזוהים. השדות למדידות החדשות עדיין ריקים. המדידות הקודמות הן להשוואה. הן אינן תוצאות הבדיקה החדשה.

    מזינים את המדידות פעם אחת, בשטח.
    איש השטח מתעד את זמן התראת הזרימה ואת הלחצים בבדיקת הניקוז. נתוני הדוגמה האלה יעברו לטיוטת הדוח.

    2. הממצא והתמונה נשמרים עם הבדיקה.
    מצרפים תמונה, מיקום והערה לאותה רשומה. בדוגמה: מתז צבוע בחדר 214.

    מהנתונים האלה נוצרת טיוטה במשרד.
    אותן מדידות ואותו ממצא מופיעים בדוח. זו עדיין טיוטה. הדוח טרם אושר או נשלח.

    3. בודקים את המקור לפני שמאשרים.
    פותחים את נתוני השטח ורואים מה הוזן בבדיקה. שינויים של המשרד מתועדים בנפרד, עם הסיבה לשינוי.

    חסר פרט? מחזירים להשלמה.
    המשרד מבקש לציין היכן נמצא המתז בתוך חדר 214. הבקשה נשמרת עם הבדיקה ומופיעה אצל איש השטח.

    איש השטח רואה את ההערה מהמשרד.
    משלימים את המיקום ושולחים את הבדיקה שוב. המשרד מקבל את הנתונים המעודכנים ויכול לבדוק אותם מחדש.

    מאשרים את הדוח. הליקוי נשאר פתוח.
    אחרי הבקרה, מאשרים את הדוח לתצוגת הלקוח. אישור הדוח אינו אישור לכך שהליקוי תוקן.

    הדוח נשמר עם היסטוריית המערכת.
    פותחים את הדוח הנוכחי או חוזרים לבדיקה קודמת. אותו אתר, אותה מערכת והבדיקות שבוצעו בה.

    תראו איך זה עובד עם הטופס שלכם.
    שלחו טופס בדיקה ודוח לדוגמה. דוגמה לטופס אחד ללא עלות, בתוך 3 ימי עבודה. אם נדרש יותר זמן, אעדכן מראש.
