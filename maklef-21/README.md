# 21 עם איתי

Interactive Hebrew concept for Itai Maklef's personal 21-day habit challenge. Uses the Fitnet presentation structure but a separate product flow: short goal setup, one to five personal habits, optional reminder times, daily check-in, 21-day map, reflection and continuation with the coach.

Original SVG landscape illustration, Rubik typography, navy/sand/sage palette. No private call transcript, pricing or negotiation details are included.

## Behavior

- Data stays in this browser under `maklef-21-demo-v1`.
- The challenge day advances by local calendar date from the start date.
- The preview selector can show days 1, 7 and 21; these records are separate and temporary.
- Reminder controls are illustrative; no notifications, accounts, payment or coach dashboard are connected.
- Contact opens a WhatsApp draft for the user to review and send. Nothing is sent automatically.
- Daily sayings and default habit targets are proposed content, not coach-approved guidance.

## Run

Serve the repository with a static HTTP server and open `/maklef-21/`.
No build step or dependencies. Main-branch GitHub Pages deployment serves the same path.
