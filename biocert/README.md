# BioCert reporting preview

Client-facing preview at `/biocert/`, prepared 28 October 2026. No original client report, client identity, call transcript, pricing discussion or private correspondence is published. The logo was extracted from BioCert's supplied report. All equipment and customer examples are fictional.

Sources: BioCert homepage, about page and equipment services page; discovery conversation and supplied report. Source evidence and commercial analysis are retained privately and excluded from this deployment.

Working interactions: switch among three report variants; edit equipment/customer details and wording; enter numeric readings; calculate descriptive mean/min/max and illustrative volumes; record test results and instrument details; see the report update; save/reopen/delete up to 20 device-local drafts; print a draft or editable procedure outline with the browser's Save as PDF option.

This is a public link with `noindex,nofollow,noarchive`, not a private application. No confidential data should be entered. No login, backend, cloud synchronization, integrations, email delivery, automatic PDF download, signature, pass/fail calculation, or regulatory compliance is implemented. Technical methods, equipment-specific criteria, exact final report layout and controlled procedure content require BioCert approval. The fume hood and zoned layouts are illustrative, pending the actual worksheets. The source worksheet has a different reading grid; the compact preview grid is explicitly identified as an example.

Deployment is static GitHub Pages from main. Publish only the `biocert/` directory. Preserve other website content and unrelated working changes.
